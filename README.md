# IT-Helpdesk-Ticket-Performance-Dashboard
Interactive Excel dashboard built on 100,000 IT support tickets to track resolution rates, response times, and customer satisfaction.
Project Overview
This project is an interactive Excel dashboard built to analyze 100,000 IT support helpdesk tickets. It explores ticket resolution patterns, customer satisfaction, and support performance across different channels, regions, and priority levels.
The goal was to turn raw helpdesk data into clear, actionable insights that a support manager or operations team could use to identify bottlenecks and improve service quality.

## Dataset

Source: Kaggle - IT Support Helpdesk Dataset

Size: 100,000 tickets

Key fields: Ticket ID, Status, Priority, Channel, Region, Issue Type, Resolution Time (hours), CSAT Score

EXCEL FILE: https://github.com/madiharoheen8/IT-Helpdesk-Ticket-Performance-Dashboard/blob/main/IT%20Helpdesk%20Ticket%20Performance%20Dashboard.xlsx


## Tools Used

Microsoft Excel

Pivot Tables
Slicers (interactive filters)
Charts and visualizations
IF formulas for data categorization




## Dashboard Features
The dashboard includes the following interactive visuals:

Ticket Resolution Status — Resolved vs. Unresolved ticket breakdown
Most Common Issue Types — Ranked count of ticket categories
Average Resolution Time by Priority — How long tickets take to resolve based on urgency
CSAT Score by Channel — Customer satisfaction across support channels
Urgent Tickets by Region — Geographic breakdown of high-priority tickets
Interactive Slicers — Filter all visuals by Channel, Region, and Priority


## Key Insights

50.1% of tickets were resolved (50,131 out of 100,000)
Urgent tickets resolved fastest at an average of 4.0 hours
Low priority tickets took the longest at an average of 40.2 hours
Overall CSAT score is 2.2 out of 5 — indicating significant room for improvement in customer satisfaction across all channels
CSAT scores are consistent across channels (2.2–2.3), suggesting the satisfaction issue is systemic rather than channel-specific




## How to Use

Download the .xlsx file
Open in Microsoft Excel (2016 or later recommended)
Go to the Dashboard sheet
Use the Channel, Region, and Priority slicers to filter the visuals interactively
